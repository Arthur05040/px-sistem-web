# px-sistem-web
O PX-Sistem-Web é um console web desenvolvido para oferecer uma experiência prática, acessível e intuitiva diretamente pelo navegador. Destinado a estudantes, entusiastas de tecnologia e desenvolvedores, o projeto busca simplificar o acesso às suas funcionalidades, com foco em usabilidade, leveza e compatibilidade com diferentes dispositivos
